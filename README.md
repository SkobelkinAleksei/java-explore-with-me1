# Explore With Me 🎟️🌍

В рамках дипломного проекта было создано приложение, представляющее собой интерактивную афишу мероприятий. Пользователи могут предложить мероприятие, собрать компанию участников и отслеживать активность других пользователей.

## Основные особенности ⚙️

- ✅ Микросервисная архитектура для гибкости и масштабируемости.
- ✅ Безопасность аутентификации и авторизации.
- ✅ Сбор аналитики для отслеживания активности пользователей.
- ✅ Модерация событий администраторами.

## Используемые технологии 🛠️

- **Backend:** Java 11, REST API, Spring Boot, PostgreSQL, JPA/Hibernate, Lombok
- **Инфраструктура:** Docker, microservices architecture
- **Тестирование:** Unit-тесты (в планах покрытие тестов)
- **Документация и тестирование API:** Postman

## Архитектура проекта 📊

Проект разбит на три основных модуля:

- **Gateway Service:** Авторизация и передача запросов другим службам.
- **Main Service:** Основной модуль с бизнес-логикой и обработкой запросов.
- **Statistics Service:** Хранение статистики просмотра и формирование отчетов.

## Endpoints API 🔗

API основного сервиса разделено на публичную, приватную и административную зоны:

- **Public API:** Доступ без авторизации.
- **Private API:** Только зарегистрированные пользователи.
- **Administrative API:** Только администраторы системы.

Доступные возможности API включают:
- Управление событиями.
- Категории и подборки событий.
- Работа с комментариями.
- Поиск и фильтрация событий.
